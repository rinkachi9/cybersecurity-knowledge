## What it is?

**Web-based attacks** are cyberattacks that target **web applications**, **web servers**, or **users interacting with websites**. These attacks exploit vulnerabilities in the application’s design, code, or configuration to:

- Steal data (e.g., credentials, credit cards)
- Hijack sessions
- Manipulate inputs or outputs
- Gain unauthorized access
- Disrupt service availability

These attacks are common due to the **exposure of web apps to the internet** and are often automated using bots and scanners.
