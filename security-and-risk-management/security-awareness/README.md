# Security awareness

Security awareness helps people recognize and respond to attacks that target human decisions. These notes explain social engineering and user focused attacks. Credential guessing techniques have their main home in identity and access management.

## Reading order

1. [User based attacks](user-based-attacks.md): Attacks that target users instead of software.
2. [Social engineering](social-engineering/README.md): Manipulation, phishing and physical access tactics.

See [credential attacks](../../identity-and-access-management/credential-attacks/README.md) for password guessing and spraying.
