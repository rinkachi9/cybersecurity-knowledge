# Identity and access management

This CISSP domain covers identification, authentication, authorization, federation and the lifecycle of access rights. Credential attack notes explain failures that identity controls must resist.

## Reading order

1. [Identity and access](identity-and-access/README.md): Authentication, authorization, tokens and protocols.
2. [Credential attacks](credential-attacks/README.md): Password guessing and password spraying.

Privileged access management and identity provisioning do not yet have dedicated notes.
