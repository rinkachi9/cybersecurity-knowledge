# Governance and compliance

Managing security as an organizational discipline: risk, control frameworks and standards.

## Notes

### Risk management

Risk management notes.

Entry point: [risk-management](risk-management/README.md).

- [Information Risk Management (IRM)](risk-management/information-risk-management.md): Risk as a decision-making discipline for information.
- [Risk Management Framework (RMF)](risk-management/risk-management-framework.md): The NIST process for managing security and privacy risk over the system lifecycle.

### Frameworks

Control and security frameworks.

Entry point: [frameworks](frameworks/README.md).

- [Cybersecurity Framework (CSF)](frameworks/nist-cybersecurity-framework.md): The NIST CSF functions, categories and profiles.
- [Security controls](frameworks/security-controls.md): How the CSF functions translate into concrete controls.
- [Center for Internet Security (CIS) Controls Framework](frameworks/cis-controls.md): The CIS Controls prioritized safeguards.
- [Cloud Security Alliance Cloud Controls Matrix (CSA CCM)](frameworks/csa-cloud-controls-matrix.md): The CSA control framework for cloud computing.
- [Google Security and Resilience Framework (SRF)](frameworks/google-security-and-resilience-framework.md): The Google Cloud security and resilience framework.

### Standards

Formal standards.

Entry point: [standards](standards/README.md).

- [ISO/IEC 27001](standards/iso-iec-27001.md): The international standard for information security management systems.
