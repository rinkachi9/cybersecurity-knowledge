# Security operations

This CISSP domain covers monitoring, investigations, incident response, vulnerability management, recovery and the operation of security controls. Threat intelligence and attack notes support detection and response work.

## Reading order

1. [Threats and attacks](threats-and-attacks/README.md): Technical attack patterns and attacker activity.
2. [Threat intelligence](threat-intelligence/README.md): Sources and use of information about threats.
3. [Vulnerability management](vulnerability-management/README.md): Vulnerability identifiers, severity and management concepts.
4. [Defensive operations](defensive-operations/README.md): Detection, security operations centers and incident response.

Digital forensics, backup strategy and disaster recovery do not yet have dedicated notes. The [ISC2 CISSP Exam Outline, effective April 15, 2024](https://edge.sitecorecloud.io/internationf173-xmc4e73-prodbc0f-9660/media/Project/ISC2/Main/Media/documents/exam-outlines/CISSP-Exam-Outline-April-2024-English.pdf) defines this domain in sections 7.1-7.15.
