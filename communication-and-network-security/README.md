# Communication and network security

This CISSP domain covers secure network architecture, network components and communication channels. All notes live in the network security section, which is split into 13 subareas by layer and by function: foundations, link layer, core protocols, DNS, wireless, secure transport, architecture, traffic filtering, network attacks, monitoring and detection, cloud and modern networks, OT and IoT, and operations. Voice and collaboration channels and third-party connectivity (section 4.3) are not written yet.

## Reading order

1. [Network security](network-security/README.md): From the network threat model and protocol weaknesses to segmentation, zero trust, filtering, secure transport, monitoring and network incident response.
