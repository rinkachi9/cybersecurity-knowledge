# OT and IoT network security

Securing networks full of devices that cannot secure themselves: industrial control systems and the broader world of embedded connected devices. The shared principle is to secure the network around endpoints that are insecure by design and cannot be patched.

## Notes

- [OT network security](ot-network-security.md): industrial control systems, the Purdue model, IEC 62443 zones and conduits, and the critical IT/OT boundary.
- [IoT network security](iot-network-security.md): isolating, egress-controlling and monitoring embedded devices; the lesson of Mirai.
