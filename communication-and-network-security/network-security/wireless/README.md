# Wireless security

Securing the radio link, where any attacker within range can listen and transmit without a physical connection. These notes cover the Wi-Fi security protocols, enterprise authentication, the attacks against wireless, and short-range technologies like Bluetooth.

Read [Wi-Fi security protocols](wifi-security-protocols.md) first.

## Notes

- [Wi-Fi security protocols](wifi-security-protocols.md): WEP to WPA3, the 4-way handshake, SAE, KRACK and PMF.
- [Enterprise Wi-Fi](enterprise-wifi.md): 802.1X/EAP over the air and the critical role of server-certificate validation.
- [Wireless attacks](wireless-attacks.md): evil twin, rogue AP, deauthentication, handshake capture, with detection and mitigation.
- [Bluetooth and short-range wireless](bluetooth-and-short-range.md): pairing weaknesses, tracking, KNOB/BlueBorne and hygiene.

These notes are conceptual: the namespace lab has no radio, so examples are described rather than run.
