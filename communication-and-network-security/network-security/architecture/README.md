# Network security architecture

How a network is structured to contain compromise and limit what an attacker can reach: zones and boundaries, coarse and fine segmentation, protecting the controls themselves, and the modern move away from location-based trust.

Read [security zones and DMZ](security-zones-and-dmz.md) and [network segmentation](network-segmentation.md) first; the rest build on them.

## Notes

- [Security zones and DMZ](security-zones-and-dmz.md): trust levels, the DMZ buffer, and zone models.
- [Network segmentation](network-segmentation.md): dividing the network and enforcing allowed flows; north-south vs east-west.
- [Microsegmentation](microsegmentation.md): per-workload policy to stop lateral movement inside a zone.
- [Management plane security](management-plane-security.md): isolating and protecting administrative access, out-of-band management.
- [NIST zero trust architecture](nist-zero-trust-architecture.md): the SP 800-207 model, its seven tenets, logical components and deployment approaches.
- [Zero-trust networking](zero-trust-networking.md): removing location-based trust, ZTNA as the VPN successor.
- [SASE and SSE](sase-and-sse.md): delivering network security from the cloud edge.
