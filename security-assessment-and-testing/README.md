# Security assessment and testing

This CISSP domain covers assessment strategies, control testing, audits, test evidence and reporting. The current note compares red, blue and purple team exercises; authorized offensive testing remains planned.

## Reading order

1. [Red, blue and purple teams](red-blue-purple-teams.md): Roles and collaboration during security exercises.
2. [Offensive security](offensive-security/README.md): Planned material for authorized penetration testing.

Application testing methods have their main home in [software development security](../software-development-security/application-security/testing/README.md). Vulnerability management has its main home in [security operations](../security-operations/vulnerability-management/README.md). Control audits and general assessment methods do not yet have dedicated notes.
