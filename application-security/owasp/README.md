# OWASP

Notes on the Open Worldwide Application Security Project: what it publishes, the Top 10 and the design principles it teaches.

## Notes

Recommended reading order:

- [OWASP](owasp.md): The OWASP foundation, its flagship projects (Top 10, ASVS, WSTG, SAMM, Cheat Sheets and others) and how they fit together.
- [OWASP security principles](owasp-security-principles.md): The 16 security design principles of the OWASP Developer Guide, their origin, trade-offs, CWE and NIST mappings, a tested example and a design review checklist.
- [OWASP Top 10](owasp-top-10.md): The list of the ten most critical web application security risks.
