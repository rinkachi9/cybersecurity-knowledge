# Asset security

This CISSP domain covers the classification, ownership, handling, retention and lifecycle of information and other assets. The current material covers asset management, data protection (DLP and DSPM) and privacy; classification and data lifecycle topics remain to be written.

## Reading order

1. [Asset management](asset-management/README.md): Inventory, ownership, criticality and lifecycle of assets, with a tested reconciliation script.
2. [Data protection](data-protection/README.md): Controls for data in use, in transit and at rest, currently DLP and DSPM.
3. [Privacy and data protection](privacy-and-data-protection/README.md): Privacy risk and the protection of personal data.

## Planned topics

- Information and asset classification
- Data retention, remanence and destruction
- Data protection across storage, use and transfer
