# Asset security

This CISSP domain covers the classification, ownership, handling, retention and lifecycle of information and other assets. The current material focuses on privacy and data protection; asset inventory and data lifecycle topics remain to be written.

## Reading order

1. [Privacy and data protection](privacy-and-data-protection/README.md): Privacy risk and the protection of personal data.

## Planned topics

- Information and asset classification
- Asset ownership and inventory
- Data retention, remanence and destruction
- Data protection across storage, use and transfer
