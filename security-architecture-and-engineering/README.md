# Security architecture and engineering

This CISSP domain covers secure design principles, security models, system architecture, cryptography and security capabilities of infrastructure. The current notes cover cryptography, cloud and operating system controls, AI systems and a planned component security section.

## Reading order

1. [Design principles](design-principles/README.md): Defense in depth and related design choices.
2. [Cryptography](cryptography/README.md): Hashing, password hashing and public key infrastructure.
3. [Operating system security](operating-system-security/README.md): Isolation and operating system controls.
4. [Cloud and infrastructure security](cloud-and-infrastructure-security/README.md): Cloud posture and infrastructure design.
5. [AI security](ai-security/README.md): Secure design guidance for AI systems.
6. [Component security](component-security/README.md): Planned notes on hardware and firmware security.
