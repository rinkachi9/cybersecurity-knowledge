# Component security

This section is planned for hardware and firmware security. Component security sits within the CISSP security architecture and engineering domain because the exam outline covers information system security capabilities, trusted platform modules and embedded systems.

## Planned topics

- Hardware roots of trust and secure boot
- Firmware security and update integrity
- Side channels and physical access boundaries
